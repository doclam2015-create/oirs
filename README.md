# Respuesta a reclamo OIRS

App de una sola pagina para el Servicio de Urgencias del Hospital Militar del Norte.

Arma el texto completo -instrucciones, tiempos de espera por categorizacion, ejemplo
de estilo y el caso- y lo copia al portapapeles para pegarlo en cualquier chat de IA
(ChatGPT, Gemini o Claude). No usa API ni claves: el costo lo cubre la suscripcion
que ya tengas.

Las instrucciones y los conocimientos son editables desde la propia app y se guardan
en el dispositivo.

**No contiene datos de pacientes.** El ejemplo de estilo esta anonimizado y los datos
de cada caso se escriben en el telefono, nunca se publican aqui.
